# Research examples

- [`idr_contact_switching`](idr_contact_switching) demonstrates direction-sensitive transient-contact switching and the Python recurrence/graph analysis API on a deterministic IDR-like trajectory.
- [`peptide_surface_adsorption`](peptide_surface_adsorption) demonstrates an approach → contact → reorientation → stable-adsorption mechanism using surface distance, orientation, `FOLLOWED_BY`, `WITHIN`, and `FOR`.

The trajectories are intentionally tiny, auditable fixtures for validating semantics. They are not physical benchmark systems and their illustrative cutoffs should not be transferred to experimental analyses without domain-specific justification.
