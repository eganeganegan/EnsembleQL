# Changelog

All notable changes to EnsembleQL are documented here. The project follows [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-09-07

### Added

- C++20 streaming execution engine with Python and command-line interfaces.
- Declarative molecular observables for contacts, distances, radii of gyration, hydrogen bonds, dihedrals, helix geometry, SASA, RMSD, coordination, salt bridges, aromatic stacking, surface distance, and orientation.
- Temporal event operators, recurrence statistics, transition analysis, motifs, event graphs, and state-transition networks.
- Built-in XYZ and PDB readers plus an optional Chemfiles backend for common molecular-dynamics formats.
- Orthorhombic and triclinic periodic-boundary handling with topology-aware molecule reconstruction.
- Published scientific-validation fixtures with independent MDAnalysis, MDTraj, and NumPy references.
- Linux and macOS CI, benchmark coverage, release-wheel testing, and trusted PyPI publishing automation.
